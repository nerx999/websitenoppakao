📘 วิธีติดตั้งหลังดาวน์โหลด

ทำตามขั้นตอนง่ายๆ นี้ เพื่อติดตั้งและรันเกมได้ทันที!

1. ดาวน์โหลดไฟล์ให้ครบ

ตรวจสอบว่าคุณได้ดาวน์โหลดไฟล์ต่อไปนี้แล้ว:

  • เกม: simple_game.py
  • (ถ้ามี) รูปหรือเสียงประกอบ: โฟลเดอร์ assets/

2. เปิด Command Prompt

กดปุ่ม Windows + R → พิมพ์ cmd → กด Enter

3. ติดตั้ง pygame (ถ้ายังไม่ได้ติดตั้ง)

พิมพ์คำสั่งต่อไปนี้ใน Command Prompt:

pip install pygame

4. รันเกม

ไปที่โฟลเดอร์ที่เก็บไฟล์เกม (ใช้คำสั่ง cd) แล้วพิมพ์:

python simple_game.py

เกมจะเปิดขึ้นทันที! 🎮

💡 เคล็ดลับจาก noppakao

• ถ้าใช้ Windows และมีหลายเวอร์ชัน Python — อาจต้องใช้ py simple_game.py แทน

• อย่าลืมตรวจสอบว่า Python อยู่ใน PATH — ใช้ไฟล์ Python_Path_Setup_by_noppakao.exe ช่วยได้!
