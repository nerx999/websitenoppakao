📥 ดาวน์โหลด Pygame สำหรับ Windows

พร้อมวิธีติดตั้งง่ายๆ ไม่ต้องเข้าเว็บหลายรอบ

⚠️ ข้อควรระวังก่อนดาวน์โหลด

กรุณาเลือกไฟล์ที่ตรงกับเวอร์ชัน Python ที่คุณใช้อยู่ เช่น:

  • Python 3.7 → ใช้ไฟล์ที่ลงท้ายด้วย py3.7
  • Python 3.8 → ใช้ไฟล์ที่ลงท้ายด้วย py3.8
  • ถ้าไม่แน่ใจ ให้พิมพ์ python --version ใน Command Prompt

หมายเหตุ: ถ้าคุณเคยติดตั้ง pygame มาก่อน โปรดลบโฟลเดอร์เก่าออกก่อน (เช่น c:\python25\lib\site-packages\pygame)

pygame-1.9.1.win32-py2.7.msi

ขนาด: 3MB | เหมาะกับ Python 2.7

pygame-1.9.1.release.win32-py2.5.exe

ขนาด: 3MB | เหมาะกับ Python 2.5

pygame-1.9.1.win32-py2.6.msi

ขนาด: 3MB | เหมาะกับ Python 2.6

pygame-1.9.2a0.win32-py2.7.msi

ขนาด: 6.4MB | เวอร์ชันใหม่กว่าสำหรับ Python 2.7

pygame-1.9.2a0.win32-py3.1.msi

ขนาด: 6.4MB | เหมาะกับ Python 3.1

pygame-1.9.2a0.win32-py3.2.msi

ขนาด: 6.4MB | เหมาะกับ Python 3.2

หมายเหตุเพิ่มเติม

• สำหรับ Windows 64-bit: ให้ใช้เวอร์ชัน 32-bit แทน (เพราะ pygame ยังไม่มีเวอร์ชัน 64-bit อย่างเป็นทางการ)

• ถ้าต้องการ Numeric สำหรับ Python 2.5 ให้ดาวน์โหลดเพิ่มเติมจาก ลิงก์นี้ (ไม่จำเป็นสำหรับ Python 3.x)
